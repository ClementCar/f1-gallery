# F1 Gallery – Projet Personnel
## Description

F1 Gallery est un projet personnel de web application permettant de suivre les Grands Prix de Formule 1 en direct et de découvrir les équipes et pilotes.
L’objectif principal est de créer une interface interactive, responsive et facile à utiliser où les utilisateurs peuvent :

  - Consulter les équipes et pilotes

  - Suivre les classements en temps réel

  - Suivre les Grands Prix au fur et à mesure


## 🎯 Fonctionnalités prévues

  - Présentation détaillée des équipes et pilotes

  - Tableau des classements pilotes et équipes

  - Suivi en direct des Grands Prix via des API publiques

  - Interface responsive adaptée à mobile et desktop


## 🛠 Technologies utilisées

  - Frontend : Angular / Ionic

  - API : Consommation d’APIs publiques pour les données F1

Le projet n’utilise pas de backend ni de base de données : toutes les données sont récupérées directement via les APIs.
